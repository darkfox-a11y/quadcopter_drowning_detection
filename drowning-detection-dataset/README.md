# drowning-detection-dataset

This folder previously contained the original self-made drowning dataset used during early experimentation.

The GitHub-facing repository has now been refocused on the DJI003-derived dataset workflow and the associated YOLOv8n fine-tuning results.

Current project documentation lives in the repository root:

- `README.md`
- `datasets/dji003_priority_drowning_v2/data.yaml`
- `datasets/dji003_priority_drowning_v2/summary.csv`
- `reports/dji003_priority_finetune/`

The original full self-made dataset remains local-only and is intentionally excluded from the cleaned GitHub version of the project.
